# Стилистика

Лендинг для записи в закрытое тестирование цифрового гардероба.
React, Vinext, Cloudflare D1. Основная страница — `app/landing.tsx`; стили — `app/globals.css`.

## Интерфейс

В блоке «Что даст Стилистика?» показана горизонтальная лента семи возможностей в общем контейнере `.wrap`. Фон остаётся на всю ширину страницы, с запасом ткани ниже подписи. `app/wardrobe/benefits.tsx` использует Embla Carousel с `loop: true`, без автопрокрутки. Доступны свайп, стрелки, семь индикаторов и клавиши ←/→, Home/End при фокусе на ленте. Стили ленты — `benefits.css`, свободные композиции примеров — `feature-preview.tsx` и `feature-preview.css` в той же папке. В примере консультации есть рабочая кнопка просмотра образа в доступном диалоге; неактивные слайды исключены из фокуса.

Область прокрутки и каждый слайд занимают ширину экрана, а сетка содержимого находится во вложенном `.wrap.feature-slide-layout`. Поэтому в покое сохраняется общая сетка страницы, а во время перехода элементы уходят до края экрана без обрезания на границе контейнера.

Ткань движется вместе с фактическим положением ленты. Три сгенерированных продолжения льна соединены перекрытием 220px с мягкой маской в длинную панораму. Собственные полупрозрачные края фотографий исключены кадрированием верхних 82%; общая SVG-маска `public/images/fabric-panorama/edge-mask.svg` задаёт единственный нижний контур всей полосы. На границе периода совпадают высота и горизонтальная касательная контура, поэтому повтор не даёт двойного края. Полный период проходит за семь функций, без зеркальных повторов на каждом слайде. Три копии панорамы позволяют перейти через её край в обе стороны. `fabric-motion.ts` разворачивает прогресс через границы зацикливания. При сокращённом движении фон неподвижен, переходы по кнопкам мгновенные. Проверка непрерывности: `node --experimental-strip-types scripts/fabric-motion-test.mjs`. Активы и промпты: [docs/fabric-panorama.md](docs/fabric-panorama.md).

Лента представляет разрабатываемые функции веб-приложения; изображения интерфейса — примеры, а не действующие инструменты. Большая фотосекция гардероба находится в `app/wardrobe/lab.tsx`.

Тексты семи функций сохранены в формулировке автора проекта; консультация разбита на три абзаца без сокращений. Палитра показывает три нейтральных оттенка соответствующих вещей. В примере ленты есть два образа, подписи авторов и демонстрационное обсуждение. Погода и одежда расположены в отдельных зонах сетки; результат распознавания связывает номера на исходном фото с категориями, цветами и характеристиками. Виртуальный гардероб показан без вешалок. Новые изображения и промпты: [docs/feature-v3-images.md](docs/feature-v3-images.md).

Первый экран занимает ширину окна и использует фотографию `public/images/city-day-hero.webp` с текстом поверх неё. Ниже находится большая панорама капсулы `public/images/capsule-panorama.webp`. Для мобильных экранов предусмотрены отдельное кадрирование первого фото и затемнение под текстом. Шаги, статусы разработки, условия участия и ответы оформлены фоновыми блоками без декоративных разделительных линий. Обе фотографии созданы встроенным ImageGen; исходники сохранены в игнорируемой папке `work/original-assets`, полные промпты — в `ASSETS.md`.

Фотографии посетителей не загружаются. Персональное распознавание и рекомендации относятся к разрабатываемому веб-приложению.

FAQ использует готовый компонент `components/ui/accordion.tsx` с `type="single"` и `collapsible`: в группе может быть открыт один ответ, повторное нажатие закрывает его. Поддерживается клавиатурная навигация Radix.

Шрифт Onest размещён локально в `public/fonts/onest-variable.ttf`. Лицензия — `public/fonts/OFL-Onest.txt`; источник — [Google Fonts](https://github.com/google/fonts/tree/main/ofl/onest). Красно-оранжевый `#c83f25` используется для кнопок и небольших акцентов. Большие поверхности нейтральные.

## Локальная разработка

Требуется Node.js 22.13 или новее. В Windows используйте `npm.cmd`, если выполнение PowerShell-скриптов отключено.

1. Установите зависимости: `npm.cmd run install:ci`.
2. Соберите проект: `npm.cmd run build`.
3. Примените только ещё не применённые SQL-миграции из `drizzle/` по порядку к локальной базе:

```powershell
node --import ./scripts/sites-env.mjs ./node_modules/wrangler/bin/wrangler.js d1 execute DB --local --config dist/server/wrangler.json --persist-to .wrangler/state --file drizzle/0000_fantastic_wolfsbane.sql
node --import ./scripts/sites-env.mjs ./node_modules/wrangler/bin/wrangler.js d1 execute DB --local --config dist/server/wrangler.json --persist-to .wrangler/state --file drizzle/0001_lucky_power_pack.sql
node --import ./scripts/sites-env.mjs ./node_modules/wrangler/bin/wrangler.js d1 execute DB --local --config dist/server/wrangler.json --persist-to .wrangler/state --file drizzle/0002_free_tyrannus.sql
```

4. Для проверки админки создайте игнорируемый `.dev.vars` с `ADMIN_EMAIL=seedy@sites.test`.
5. Запустите `npm.cmd run dev`. Локальный вход: `/signin-with-chatgpt?return_to=/admin`.
6. Интеграционная проверка: `node --experimental-strip-types scripts/smoke-test.mjs`. Скрипт создаёт только локальную тестовую заявку с префиксом `smoke_`.

Применённые миграции не меняйте и не запускайте повторно. Создавайте новые через `npm.cmd run db:generate`. Локальная и размещённая базы независимы.

## Заявки и доступ

`POST /api/applications` принимает имя, возрастную группу, Telegram, необязательные пол (`female` / `male`), телефон и явное согласие. Устройство и интересующая задача необязательны. Если пол не указан, хранится `NULL`; старые клиенты без этого поля поддерживаются.

Telegram нормализуется, дубликаты не создаются. Есть серверная проверка, ограничение размера запроса, Origin, honeypot и ограничение частоты по временному хешу IP. Параметр `route_summary` остаётся nullable для совместимости с сохранёнными заявками; текущая форма его не отправляет.

Страница `/admin` и CSV `/api/admin/export` доступны только пользователю ChatGPT, чей подтверждённый email совпадает с секретом Sites `ADMIN_EMAIL`. CSV содержит BOM для Excel и защиту от формул.

В панели показываются пол и распределение сохранённых заявок по возрастным группам. Заявки без пола отмечены «Не указан». Устаревшие счётчики демо и скачивания маршрута скрыты; их исторические данные сохранены в базе.

`POST /api/events` увеличивает дневные обезличенные счётчики. Они не содержат контактов и идентификаторов посетителей и не являются числом уникальных людей. Текущая страница отправляет события открытия страницы и просмотра формы.

Контакт команды для вопросов, изменения и удаления заявки: https://t.me/DuImaran.

## Размещение

Sites ID хранится в `.openai/hosting.json`. Повторно создавать Site не нужно. Сборка и публикация выполняются через Sites с сохранением аудитории. Секреты задаются через настройки окружения Sites.

Изображения и исходные промпты описаны в [ASSETS.md](ASSETS.md). Продуктовые утверждения о команде и стадии разработки основаны на предоставленной презентации; даты запуска и цена приложения пока не объявлены.
